# 🗺️ Route Tracker App

A robust cross-platform mobile application built with **Flutter** and **Dart** that tracks, records, and manages user routes in real-time. 

## ✨ Features
* **Clean Architecture:** Implemented to ensure a highly scalable, maintainable, and testable codebase.
* **Real-time Location Tracking:** Accurately track user movement using GPS.
* **Interactive Maps:** View current location and past routes on a map.
* **Route History:** Save and review previous trips with detailed stats (distance, duration).
* **Clean UI/UX:** Intuitive, and responsive design tailored for both Android and iOS.

## 🛠️ Technologies & Tools
* **Framework:** [Flutter](https://flutter.dev/)
* **Language:** [Dart](https://dart.dev/)
* **Maps Integration:** Google Maps SDK
* **Location Services:** `geolocator` / `location` packages
* **Architecture:** Clean Architecture principles

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable version)
- Android Studio / VS Code
- A valid Google Maps API Key

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Moamed1010/Route-Tracker-App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Route-Tracker-App
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Set up your Google Maps API Key in the respective Android and iOS configuration files.
5. Run the app:
   ```bash
   flutter run
   ```
